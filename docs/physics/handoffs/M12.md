# M12 handoff

## Delivered behavior

M12 completes the reactive physics plan: every control is in the game, one route shows every system, and a matrix proves each switch the same way.

- **World physics panel** (`src/app/world-physics.ts`).
  - **How players reach it:**
    - O; with the mouse over an object, O also inspects that object;
    - the target button beside I/K/P on the HUD, which also works by touch;
    - the button in the game-mode menu;
    - "World physics · O" in the pause menu.
  - **Pausing:** solo menus pause time, so changes apply at once. A co-op host's changes apply at the next tick.
  - **Where you stand:** every effective value with its source, the session master, and "Undo every live change".
  - **Choose where a change applies:** whole land, this area, or a named region of this area. Region names: the combination's name for an M11 cluster, Calm/Wild ring, Market, Pass-through patch, Creature circle, Your region.
  - **Presets:** four cards, each with an explanation and its exact differences from Reactive.
  - **Switches:** Default/On/Off, or a numeric field where empty means the default. Each has a short explanation, where its value comes from and its effect where you stand.
  - **Region editing:** Center on me, Larger, Smaller, Priority ±5, New region around me, Remove (custom regions only), Clear live changes here, Reset to authored. The selected region's true bounds are drawn while the panel is open.
  - **Inspector:** reached by O over an object, Pick on the map (Esc returns), Nearest to me, or the nearby list. It shows kind, material, mass, motion (free, fixed, frozen, reactivation blocked), durability, mechanism, regions, every value that differs from Reactive with its source, reaction status, last reaction and last push.
  - **Guests** see the same values with every control disabled.
- **Profiles:** areas use Reactive (engine defaults) and the town uses Sanctuary. No rollout switch remains: the M03 patches keep honest names, and the lab panel is "Physics lab · developer tools" (D97).
- **Showcase route:** [`examples/showcase.json`](../../../examples/showcase.json), six beats in Brambleburst, each starting from a clean scene with ordinary input (D95):
  1. destructible scenery: the pen fence slashed apart;
  2. a launched prop kill: a thrown crate kills a stalker, credited to you;
  3. a physical rig death: a ragdoll that Whorl flings;
  4. a jointed mechanism: the sprung launcher fires;
  5. a material chain: an oil jar in the brazier's coals;
  6. a regional off/on: the calm ring keeps a pot whole, the panel switches it to Reactive, the same slash breaks it, and Reset to authored makes it calm again.

  `npm run showcase` plays it headless; `npx playwright test e2e/showcase.spec.ts` plays it in the browser (`SHOWCASE_VIDEO=1` records it). The capture is [`physics-m12-showcase.png`](../../evidence/physics-m12-showcase.png) and [`.webm`](../../evidence/physics-m12-showcase.webm).
- **Functional matrix** (`tests/physics-matrix.test.ts`, D96): all 24 policy values go through one cycle: on, off in a region, off after save/restore, off on a late-join replica, back on ([measured](../../evidence/physics-m12-matrix.json)). One more test covers the dependency combinations POLICIES.md names: master off with features on, joints off with breakage on, destruction off with impact damage on, and base combat without reactions.

## Remaining limitations

- The live production page cannot be loaded from the implementing container: its network policy denies `*.vercel.app`, and the Vercel connector's protected fetch returns 403. Production is verified as the connector's READY deployment for the merge commit; the live browser scenarios were not run against it.
- The showcase's beats each start from a clean scene (staged). One continuous run let earlier beats' debris and fire change later ground under real-time browser input (D95).
- Same-build replays are exact; cross-device bit identity is not a goal (D69, D82).
- Not optimized (D53): the corpus, routes and matrix are functional evidence, not performance targets. A later stress-test pass decides what to scale back.
- A 3,600-tick idle soak of generated lands records occasional unowned impacts on M10 set pieces in neighbouring areas (a pot or a barricade board breaks with no owner). This predates M11's follow-up and is unchanged by it. It does not block progression; a later pass should find what launches them.
- Co-op stays experimental and functional (D53); its performance is not benchmarked or tuned.
