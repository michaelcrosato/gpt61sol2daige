# M01 Rapier foundation and physical playground

Dependency: planning merged. Read the architecture's initialization, ownership and fixed-tick sections. Deliver a real backend running in both Node and the browser, with a visible playground that proves forces and contacts work.

## Steps

1. Verify and pin `@dimforge/rapier2d-compat` and its actual APIs. Add explicit initialization to browser/tool/test entry points without adding a DOM dependency to the engine. Update the lockfile; keep normal fixed stepping synchronous after readiness.
2. Create the adapter, stable body registry, unit conversion, event queue and disposal lifecycle. Start with zero gravity, fixed obstacles and dynamic circles/boxes. Establish the command boundary used by subsequent milestones.
3. Add a deliberate physics playground reachable from Agent lab. Include a crate pile, a free wheel, a fixed wall, an impulse control and a swept-motion example. Draw real body transforms and a collider overlay.
4. Add discoverable `physics` inspect/spawn/impulse/reset commands and a headless scene runner. Support a simple Rapier snapshot round trip in the playground. Expose initialization errors visibly instead of leaving a blank canvas.
5. Keep the experimental playground solo-only until M04. Preserve current game/co-op behavior outside it. Remove the old browser `fps > 20` acceptance assertion and document that performance is informational; preserve entity-count, rendering and interaction checks.

## Acceptance

- A visible body moves when pushed, spins from an off-center impulse, and contacts the wall; the corresponding headless scene reports changed poses and contact evidence.
- Repeated scene reset/dispose and failed/canceled initialization do not leave duplicate worlds, handles or stale callbacks.
- Initialization works in production build, CLI, tests and browser restore entry paths. A saved playground snapshot can be restored and stepped again.
- `npm run check`, `npm run build` and applicable browser coverage pass. Report measurements only if useful; no speed comparison is required.
