## Steps

2. Implement semantic validation before allocation and a complete scene rebuild. Test save during motion and after a region toggle. Keep exact gameplay facts and tolerate declared small physical drift where needed.
3. Extend the transport with a versioned physical-state channel/section, reliable lifecycle events, angular interpolation, scene revisions and chunked baseline transfer. Validate framing and reassembly atomically; do not overflow the existing JSON header or silently drop bodies. Provide a file/chunk import path if expanded checkpoints exceed the JSONL tool's existing line limit.
4. Add host-validated physical interaction and scoped policy actions. Guests do not solve authoritative physics. Preserve replay/inspection APIs without allocating an unused physics world every snapshot.
5. Extend leave/disconnect handling to restore a useful local physical scene and rekey owned effects. Unload/free replaced worlds on every recovery path. Remove the solo-only rollout restriction after this milestone's transport checks pass.

## Acceptance

- Save a moving crate, actor knockback and disabled region; reload and observe consistent continuation with unchanged gold/skills/rewards.
- Eight real isolated WebRTC clients see a guest move a prop and the host change a region. A late join receives its correct pose/policy before interacting; guests cannot author shared tuning.
- Missing/out-of-order baseline chunks cannot create a half-world; portal transitions cannot interpolate actors across lands.
- Host disconnect leaves each guest with its own usable build and received scene. Old saves load through the documented migration and older clients receive an explicit protocol message.
